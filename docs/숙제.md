1. **협경 + 동맹 협경** (주 1회씩, 심력 0, 심득 최대) ← 주간 1순위
2. **심력 전부 소진**
3. **시즌상점 옥어패 교환** — 심법 심득 40 → 비결돌파 상자 10

5. 태평무묘 전승 교환
6. 강호호령 6개 (리롤로 쉬운 것만)

## 1.x 목록에서 걸러낸 것
- **침중산**: 주간 콘텐츠가 아니라 **심력 회복 아이템**으로 보인다 (단일 출처, 인게임 확인 권장)
- **협력등반**: 동맹 가입 시 생기는 추가 던전(= 동맹 협경)을 가리킨 말로 보인다. 별도 콘텐츠로 확인 못 함
- **첩음 재료 풀매수**: 현재 데이터에 전용 재고 항목이 없다. 기술양성 탭으로 통합됐을 가능성. 인게임 확인 필요
- **가업·펫·무도심궁**: 2.2가 아니라 **1.8(2026-06-25)** 추가다. 무도심궁은 5인 20층, 60레벨 이상.
  주간 주기인지는 확인 못 함
