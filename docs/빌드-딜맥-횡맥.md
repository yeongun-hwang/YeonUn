# 열석 균 (딜맥 / 횡맥) 세팅

> 2026년 10월 1일 조사, 한국 서버 2.2 기준.
> **출처 경고**: 한국 커뮤니티의 열석 균 전용 가이드는 대부분 출시 직후(2026-03~04, 1.5 시절) 글이다.
> 2.0(7/23) 이후 한국어 종합 가이드는 찾지 못했다. 2.0 반영분은 Game8과 공식 패치노트로 보정했다.

## 무공
- 만설의 참격 (횡도) + 십방파진 (맥도)
- 1.5 이후 우편으로 두 무공 비급, 서리 백야·외로운 충성 심법서, 기본 무기가 함께 온다.

## 심법 4칸
| 유형 | 딜맥 (맥도 메인) | 횡맥 (횡도 메인) |
|---|---|---|
| 공용 | 결의의 노래 | 결의의 노래 |
| 핵심 | 서리 백야 | 서리 백야 |
| 3번 | 천후결 (커뮤니티명 관목결) | 천후결 |
| 4번 | **외로운 충성** | **생명의 귀환** 또는 **파괴의 서막** |

- **슬롯 위치 효과는 확인 못 함.** 커뮤니티의 "오른쪽부터 결의/서리/관목/외충"은 단순 나열이고, "6665"는 돌파 수 표기다.
- 천후결이 없으면 **무공의 경지**(청하 묘물 NPC) 0돌로 임시 대체.
- Game8은 천후결 대안으로 **전투의 노래**(차지스킬 보스 피해 +10%, 4돌 15%)를 든다.

### 돌파별 효과
**서리 백야 (금, 횡도)**
| 돌파 | 효과 |
|---|---|
| 0 | 패링 성공 → 연계 강공 '눈속의 봄기'(공식명 만설의 각성). 기세 1 소모, 2초 쿨 |
| 1 | 맥도 ~버프 중 눈속의 봄기에 안서군 연계 |
| **3** | **차지 약공·무기전환(Tab) 후에도** 눈속의 봄기 발동 → DPS 분기점 |
| **4** | 적중 시 기세 0.5 회복 + **불타는 투지 4스택** |
| 6 | 피해 +10%, 망각 3초(차징 약공 즉발 + 연계강공 쿨 초기화, 내부쿨 6초). 2.0에서 탈진 보스 전율 +2초 추가 |

**외로운 충성 (보라, 맥도)**
| 돌파 | 효과 |
|---|---|
| 0 | 차지 강공 **3단계** 추가 (2단의 약 2배) |
| 1 | 특수기(~) 쿨 1초, 철갑의 혼백 지속 증가 |
| **3** | 안서군 소환 공격 시 5초간 차지강공·안서군 **확정 치명** + 치명피해 10% (쿨 15초). **2.0에서 요구 최종 치명 70% → 75%** |
| **4** | **불타는 투지 중 차지 강공의 도검기세 소모 0** — 없으면 사이클이 끊긴다 |
| 6 | 3돌 버프 8초로, 차지강공·안서군 피해 +15%. 2.0에서 탈진 적 적중 시 차지강화 3중첩 18초 |

**결의의 노래**: 공격/치유 시 이수 1스택(외공관통 +2, 피해 +1%, 12초, 5중첩, 2초당 1회)
**천후결**: 약/강공 변형 연계 피해 시 관통당함 8초 3중첩(외공저항 2 무시 + 치명피해 2%)

### 돌파 우선순위
서리 백야 3돌 → 4돌 → 외로운 충성 3돌 → **4돌(실질 완성 지점)** → 외로운 충성 6돌 → 서리 백야 6돌

## 무공 특성 (천부)
개별 노드의 한글명은 **확인 못 함**. 게임 내 무공 → 천부에서 확인할 것. 확인된 효과 축은:
- 만설의 참격: 민첩 기반 최소 외공 / **치명 피해 증가(핵심)** / 열석 공격 증가
- 십방파진: 도검 기세 최대치 / **민첩 기반 치명률(100% 투자 필수)** / 최소 외공 기반 물리 관통

찍는 순서: **맥도 민첩-치명률 100% → 횡도 치명 피해 → 관통·외공 → 기세·열석 공격**

## 비결 3칸
| 비결 | 역할 | 획득 |
|---|---|---|
| **격랑의 파도** (커뮤니티명 "피리") | 사이클 시작. 피리 소리 직후 패링으로 캔슬 → 초탄 버리고 12.5초 지속딜만 챙김 | 망안 주둔지 오불능 스님, 연주 1회 → 퀘스트 |
| **맹수의 돌격** ("맹돌") | 사이클 마무리 딜. 2타 찌르기 + 치유감소 | 비결 퀘스트 |
| **신룡의 화염** 또는 **합마공** | 빈 구간 필러. 신룡은 강인+도트, 합마공은 광역 | 각 비결 퀘스트 |

- 탈진 구간 전용으로 **거위의 절규**(그로기 빅딜, 원기 소모 큼)도 대안.

## 사이클
**0~2돌**
```
맥도 ~ (철갑의 혼백)
→ 맥도 Q 차징 (보호막+경직, 진입기)
→ Tab 횡도 → Q(1타) → ~ → Q(2타)
→ Tab 맥도 → 차지 강공 3회
→ 구르기로 빠지고 반복
```
- `~ QQ`와 `Q ~ Q` 둘 다 가능. **2타째 Q가 반드시 불타는 투지 중이어야** 공포의 칼날이 붙는다.

**3~4돌**: 위 사이클에 `Tab` 직후 `F`(눈속의 봄기)를 끼운다. 4돌이면 투지 4스택이라 차지 강공이 4회.

**6돌 (딜맥 완성형)**
```
맥도 ~ → 격랑의 파도(피리, 패링 캔슬)
→ Tab → F → 횡도 Q(1타) → 횡도 ~(비홍의 잔상: 전율+투지) → 횡도 Q(막타: 공포의 칼날 15초)
→ Tab 맥도 → 3단 차지 강공(R 꾹) ×4
→ 연혼(Q)·신룡·맹돌로 필러 → ~ 갱신 후 반복
```

**횡맥 6돌**: 위에서 맥도 차지 자리를 `차지 약공(좌클릭 꾹, 무덤 위 서리) → F → 패링(우클릭) → F` 반복으로 바꾼다.

**탈진(그로기)**: 최대 딜 구간. 들어가기 전에 철갑의 혼백·전율·공포의 칼날을 **미리 다 깔아두고** 탈진 순간 차지 강공을 쏟는다.

**잡몹**: 횡도 ~(비홍의 잔상) 광역 + 맥도 Q 휩쓸기(팔황) + 격랑의 파도. 차징 사이클 불필요.

## 조율
우선순위: **정확도(95~100%) → 치명타 → 최대 외공 → 내공 → 민첩 → (잉여) 각성·속성 공격**

### 정확도가 왜 1순위인가
① 정확도 적중 판정 → ② 적중해야 치명/각성 판정 → ③ 적중 실패 시 찰과상(최소 공격력 기반).
즉 **정확도를 못 맞추면 확정 치명이 아예 발동하지 않는다.**
정확도 100%에서 치명+각성 합이 100%면 일반뎀·찰과상이 안 뜬다. 치명 표기 상한 80%, 관통 1pt ≒ 0.51% 딜.

### 목표 수치
- **딜맥: 최종 유효 치명률 75%** (외로운 충성 3돌의 확정 치명 조건)
- **횡맥: 75~80%**
- 확인 위치: **ESC → 육성 → 캐릭터 정보**
- 부위당 조율 줄 수는 **확인 못 함**

## 정음
| 부위 | 딜맥 | 횡맥 |
|---|---|---|
| 무기(횡도·맥도)·환·패 | 외공 관통 | 외공 관통 |
| 투구·갑옷·각반·팔보호구 | **십방파진 차지 스킬 피해 +3.0~5.0%** | **만설의 참격 약/강공 변형 피해 증가** |

## 장비 세트
단악(무기·장신구) + 현갑(방어구)

## 승음·음율 (91제, 만렙 이후)
- 86제를 승음석으로 91제로 이전. 조율 옵션·세트·정음이 유지되지만 **최대 수치의 95%까지만** 성장(5% 영구 손실). 금색 정음은 변음으로 다시 만들어야 한다.
- 실전 팁 "정음만 이식": 86제를 싸게 찍어 원하는 정음만 뽑고 승음 → 좋은 조율의 91제와 조율 교환(변음석 2 + 정음석 2). 무기 정음 1/12, 장신구 1/8, 방어구 1/6 확률을 우회한다.
- 91제는 전율 옵션 변경이 주 1회 가능(이전 획득 옵션은 재등장 안 함), 변음 8회 천장 후 정음 자유선택.

## 딜맥 vs 횡맥
| | 딜맥 (맥도 메인) | 횡맥 (횡도 메인) |
|---|---|---|
| 4번 심법 | 외로운 충성 | 생명의 귀환 / 파괴의 서막 |
| 주력기 | 3단 차지 강공 (마음속 불길) | 눈속의 봄기 (연계 강공) |
| 최종 치명 | 75% | 75~80% |
| 방어구 정음 | 십방파진 차지 스킬 피해 | 만설의 참격 변형 연계 피해 |
| 딜 | 기준 | 약 10~12% 낮음 |
| 난이도 | 움직이는 보스에서 차징 흘리기 쉬움 | 쉽고 안정적 |

→ **딜맥 권장.** 외로운 충성 4돌 전에는 횡맥처럼 굴리다가 넘어가도 된다.

## 51렙 진행 순서
1. **천후결 확보** — 량주 백작경각에서 새 17마리 + 새 보스. 없으면 무공의 경지로 땜빵
2. **비결** — 격랑의 파도(망안 주둔지 오불능) → 맹수의 돌격 → 신룡의 화염
3. **심득 투자** — 위 돌파 우선순위대로
4. **장비** — 단악 + 현갑, 정확도 100% 먼저, 그다음 치명
5. **만렙까지 미뤄도 되는 것** — 승음·음율, 정음 최적화, 세트 완성 (51제 장비는 어차피 교체된다)

### 심득 파밍처
1. **시즌 상점 주 40개 상자 (최우선, 반드시 전량 구매)**
2. 심력 20당 상자 1개 — 진수전·거점·검무장
3. 협경 — 보스당 약 5개, 주 10개
4. 유파 육성 가이드의 유파 도전 클리어 보상
5. 개봉 심법 상점 일회성 (결의의 노래 10개)
6. 음식 상인 호감도

노드당 10개 → 20개로 늘어나니 **몇 주 단위**로 본다.

## 흔한 실수
- **횡도만 쓰는 것.** 본체는 맥도다. 육성 중 횡도는 버프·짤딜용
- **투지 없을 때 Q 2타** — 공포의 칼날이 안 붙는다
- **파도 버프 후 강화 약공** — 불타는 투지가 날아간다 (구버전 글 기준, 재확인 필요)
- **차지 강공 횟수를 숫자로 외우는 것** — 버프와 기세를 보고 판단해야 한다. 글로벌은 중섭보다 버프 지속이 짧아 4타가 안 나올 때가 있다
- **정확도를 버리고 치명만 올리는 것** — 적중 실패하면 확정 치명이 통째로 날아간다

## 체감
3돌 전까지는 "느리고 밋밋한 맥도". 서리 백야 3돌에 사이클이 생기고, **4돌(기세 소모 0)에서 처음 제대로 돌며**, 6돌에서 망각 버프로 완성된다. 돌아다니는 영상은 전부 6돌/6돌 기준이라 그대로 못 따라 한다.

## 확인 못 함
천부 노드 개별 한글명, 부위별 조율 줄 수, 심법 슬롯 위치 효과, 돌파 심득 아이템의 정확한 한글명, 2.1·2.2 열석 균 밸런스 조정 여부(한국 텍스트 패치노트에 없음), 중섭 9/24 패치(전율 6→10초, 서리 백야 4·6돌 상향)의 한국 적용 여부(미적용으로 보임)
