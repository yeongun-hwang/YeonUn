> 2026년 10월 4일 조사, 한국 서버 2.2 기준.
> 주 출처: 아카 「뉴비 가이드라인 A-Z」(2026-06-23 작성, **2026-09-11 갱신**), Game8 월드 레벨·돌파표,
> 아카 성장 가이드(2026-08-18), 공식 공지. 2.0 이전 글은 표시했다.

## 한 줄 요약
**91제를 손에 쥐기 전까지는 아무것도 박지 마라.** 71~90은 레벨과 월드 레벨을 올리고, 영구 투자(첩음·무기고·심법·탐색 능력치)만 쌓는 구간이다.

## 1. 만렙과 레벨 구간

**만렙은 100이다. 95가 아니다.**
95는 2026-04-30 개편 당시 시즌3 상한이고 이후 올라갔다. Game8은 "돌파 17단계의 Lv.100이며 2.1 버전 상한"으로 적는다.

**진짜 게이트는 캐릭터 레벨이 아니라 월드 레벨(= 싱글 모드 돌파 단계)이다.**
태평무묘의 돌파 시련을 깨야 다음 단계가 열리고, 그게 캐릭터 레벨 상한을 올린다.
초반 단계에는 실시간 '탐색 일수' 조건도 붙는다.

| 돌파 | 레벨 상한 | 보상 장비 |
|---|---|---|
| 10 Unbound | 75 | **71제** |
| 11 Beyond Mortal | 80 | **71제** |
| 12 Simplicity | 85 | **81제** |
| 13 Universal View | 90 | **86제** |
| 14 Clarity | 95 | **91제** |
| 15 Understanding | 95 | 91제 |
| 16 · 17 | → 100 | **확인 못 함** (96급은 91제 승음으로 만든다) |

- **71~80 구간은 71제를 그대로 입는다. 76제는 없다.**
- 71제 → 81제 → 86제 → 91제 → (승음) 96급
- 돌파 16·17의 보상 장비와 상한 해제 조건은 확인 못 함. 게임 내 태평무묘에서 확인할 것.

### 장비 티어
71제 / 81제 / 86제 / 91제 / **96급(91제 승음)**

**100제는 한섭에 없는 것으로 보인다.** 2.2 공지 [육성 최적화] 항목에 "100단계의 전설·신화 등급 장비는 [음율석]으로 조율 초기화"라는 문구가 한 번 나오는데, 같은 문단이 "조율 초기화는 **91단계 이하** 미지원"이라 쓰고 2.1 공지는 일관되게 "96급"을 쓴다. 중섭 수치가 번역에 섞인 것으로 보인다. **확인 못 함** — 장비 상점이나 승음 화면에서 직접 확인할 것.

## 2. 경험치는 어디서 나오나 (71+)

효율 순:
1. **메인 스토리 + 강호 유산(잔편) 퀘스트** — 잔편이 4종 퀘스트 중 기본 경험치 최고
2. **탐색** — 묘물 줍기, 경계석, 보물상자, 탐색 퀘스트. 묘물은 심력 총량과 탐색 능력치도 같이 올린다
3. **은하방주(부경행주) 배** — 주 4회, 1000포인트를 채우면 경험치 뭉텅이. "초반엔 1번에 10랩"
4. **동맹 주간 이벤트** — 날로 먹는 경험치
5. **검무장 / 협경** — "한두 번만 돌아도 바로 최대치" (2025-12 글)
6. 채집(청하 대나무숲, 개봉 채석장), 현상금, 강호호령

- 심력 콘텐츠도 경험치를 주지만 주목적은 재료다.
- 대련·수련이 경험치 출처라는 건 확인 못 함.

### 경험치 캡
- 일일·주간 경험치 캡은 **확인 못 함**. 실질 캡은 돌파 레벨 상한이다.
- 상한을 넘기면 **저장 경험치**로 쌓인다. 상한이 풀려도 한 번에 안 들어오고, 뭔가 행동해서 경험치를 얻어야 저장분이 당겨져 온다.
- Game8은 저장분이 있을 때 **추가 +50%** 보너스가 붙는다고 쓴다.

### "81렙 이후 메인퀘 경험치 급감"은 근거를 못 찾았다
이전 정리(1.x 기준)에 그렇게 적혀 있었는데, 출처가 oslink.io 한 곳뿐이고 그 글은 실재하지 않는 콘텐츠명('시검 던전')을 쓰는 AI 생성 SEO 글로 보인다.
실제 구조는 다르다 — 메인 스토리에 레벨 요구치가 걸려서 **상한이 안 풀리면 진입이 막히는** 것이고, 분량도 유한하다.
아카 성장 가이드는 "청하만 클리어해도 70랩 80랩", 이후 불견산 + 채집으로 96랩이라고 쓴다.

## 3. 심력 — 구간별 어디에 털까

| 콘텐츠 | 보상 | 소모 |
|---|---|---|
| 거점 | **오금철** (비결 레벨업·돌파) | 20 / 3배 60 |
| 진수전 | 세트 장비 | 20 / 3배 60 |
| 검무장 | 심득 | 60 / 3배 180, 주 1회 추가 보상 |
| 협경 | 심득 상자 | **심력 0**, 주 1회 |

### 71~90 — 거점 위주
- **거점**을 주로 돈다. 오금철로 비결을 올리고, 첫 클리어로 **심신**(탐색 능력치)이 들어온다.
- **검무장**은 주 1회 추가 보상만 챙긴다.
- **협경**은 심력을 안 쓰니 무조건 돈다.
- **진수전에 심력을 들이붓지 마라.** 81 / 86 / 91에서 장비를 통째로 갈아치운다.
  > "다음 레벨제 뚫릴 때 희귀도만 올라가는 템에 절대 심력 갈지 마라" (2025-12 글이지만 원칙은 그대로)

### 91제 ~ 만렙 — 여기서 푼다
진수전·검무장으로 세트 장비와 조율 재료를 본격적으로 돌린다.

### 침중산 = 심력 회복 소모품이다
주간 콘텐츠가 아니다. 돌파 보상과 시즌 패스로 들어온다.
다수설은 "만렙 장비 파밍용으로 아껴둔다"이고, 못 참고 쓰는 사람도 많다.
**71렙에서는 봉인.**

- 심력 수치(20/60, 60/180)는 2026-07-28 + 2025년 글 기준. 2.2에서 바뀌었는지는 미확인.

## 5. 71렙에서 쓸 것 / 아낄 것

### 지금 태워도 되는 것
- **대율준석 · 소율준석** — 해당 레벨 전용이라 아껴도 못 쓴다. 지금 71제에 다 쓴다
- **진옥 → 첩음** — 첩음은 장비를 갈아도 안 사라지는 **영구 투자**다.
  단 빠른 성장 중이면 **무기 · 환 · 패만** 올린다
- **묘물 제출** (청하 / 개봉 / 황궁 / 하서 / 불견산) — 스펙 영향이 크다

### 아껴야 하는 것
- **율준석**(전 레벨 공용) — 91제까지 들고 간다
- **정음석 · 변음석 · 전율석** — 71제 정음은 최소한만
- **심득** — 결의의 노래는 **5돌까지만**, 나머지는 서리 백야에 몰아준다
- **침중산**

### 하지 말 것
- **원클릭 강화.** 방어구 첩음과 안 쓰는 비결(허공섭물·태극)에 재화가 새서 효율이 박살난다

## 6. 내실 — 인게임 시스템이 아니다

**"내실"은 커뮤니티 속어다.** 같은 이름의 메뉴는 없다.
누적된 영구 투자(무기고 조예, 첩음, 천부, 탐색 능력치, 심법 돌파)를 뭉뚱그려 부르는 말이다.

> "무기고 **내실** 채우는 게 좋음" (2025-12)
> "복귀유저 **내실** 안 된 상태로 91제 노랑템 대강 조율해서 끼니까 2.5 거위" (2026-06-23)

### 실제로 장비 착용을 막는 건 '탐색 능력치'다
- **메뉴**: 육성 → 캐릭터 정보 → 우측 삽·곡괭이 아이콘 → 탐색 능력치
  (2025-12-03 글 기준이라 UI가 옮겨졌을 수 있다)
- **종류**: 심신, 박식, 기량, 우아함, 시력, 조화, 지능, 음운, 기억력, 심경, 경력
- **올리는 법**: 심신 = **거점 첫 클리어** / 박식 = 묘묘냥 퍼즐 / 조화·시력 = 묘물 채집 / 경력 = 레벨업
- **적정선: 스탯 50이면 모든 장비를 착용할 수 있다.**
  71에서도 만렙에서도 이 50이 기준선이고, 그 이상은 미니게임·탐색 스킬(보물상자 표시, 낙하 피해 방지)용이다
- 별개로 **무기고 조예** 요구치가 걸리는 장비도 있다

## 7. 무기고

- **51렙 해금.** 레벨 단계별로 칸이 따로라 누적된다 (51제 넣고 61제 넣어도 51제 보너스 유지)
- **71렙 시점**: 41 · 51 · 61 단계가 **이미 다 차 있어야 한다**
- 71제는 착용 중이니 **81제로 갈아탈 때 넣는다**
- 81 → 86 → 91 넘어갈 때마다 직전 단계를 집어넣는 게 루틴이다
- **승음해서 96급이 된 장비는 91 칸에 못 넣는다.** 무기고용 91제를 따로 남겨야 한다

## 8. 지금 당장 할 일 (71렙, 순서대로)

1. **메인 스토리 밀기** — 불견산까지. 71~80 경험치 주력이고 천부 경험치도 같이 들어온다
2. **태평무묘 돌파 시련** 깨서 월드 레벨 올리기 — **이게 안 되면 레벨이 안 오른다**
3. **은하방주 주 4회** 꽉 채우기 — 경험치 효율 최상위
4. **협경 주 1회**(심력 0) + **동맹 협경** + **검무장 주 1회**(추가 보상)
5. **거점 돌기** — 오금철로 비결 레벨업, 첫 클리어로 심신 확보. **탐색 능력치 50 맞추기**
6. **묘물 전 지역 수집·제출**, 경계석 찍기
7. **진옥 → 무기·환·패 첩음**만 집중
8. **서리 백야 돌파에 심득 몰빵**. 결의의 노래는 5돌에서 정지
9. **71제는 대율준석으로만 가볍게 조율.** 율준석·정음석·변음석·전율석·침중산은 봉인
10. **81제 / 86제 갈아탈 때마다 직전 장비를 무기고에 투입**
11. **91제 + 만렙 도달 후**에 조율 → 정음 → 전율 → 승음(96급) → 음율 순으로 본격 투자

## 9. 커뮤니티 우선순위 (디시 댓글, 2026-06-07)

6일차 95렙 유저가 "거위력 23,000에서 3만 가려면 뭐 해야 하냐"고 물은 글의 답변.
2026-06 기준이라 수치는 낡았지만 **우선순위 논리는 유효하다.**

> 무술렙·첩음은 솔직히 파밍 조금이랑 돈으로 다 커버돼서 **그 둘 빨리 올리고**,
> 그다음이 좋든 싫든 빨리 못 모으는 **심법**. 그리고 **비결렙**도 올려야 되니까
> 틈틈이 자주 쓰는 비결들 돌파재료 확인하고 모아두고,
> 결국 할 거 다 하면 자기 유파에 맞는 걸로 **장비 세팅** — 이게 좀 어려움.
> 그리고 **활이랑 깍지도 세트 효과 있으니까** 제작 재료도 모아두셈. 천장 있어서 어렵진 않을 거임.

정리하면:
1. **무술 레벨 · 첩음** — 돈과 소량 파밍으로 빨리 커버된다. 먼저 올린다
2. **심법** — 시간 싸움이라 꾸준히
3. **비결 레벨** — 자주 쓰는 비결의 돌파재료를 미리 확인해 모아둔다
4. **장비 세팅** — 유파에 맞게
5. **활 + 깍지 세트 효과** — 제작 재료를 모아둔다. 천장이 있다
