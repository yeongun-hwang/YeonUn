# 명금 영 (구격) 세팅

> 2026년 10월 1일 조사, 한국 서버 2.2 기준.
> **출처 경고**: 구격 전용 2.x PvE 종합 가이드는 한국 커뮤니티에 없다.
> 아래는 공식 패치노트 + 2026년 9월 디시 실전 글 + 2.0 이전 정리글을 합친 것이다. 오래된 항목은 표시했다.

## 무공
- 구현의 검무 (검) + 격류의 파동 (창)
- 격류의 파동은 광란문 절학. 가입하거나 동굴 기연에서 훔쳐 배운다. **같은 동굴에 굶주린 늑대 심법 상자가 있다.**
- 무공은 레벨 제한 없이 훔쳐 배우기로 습득 가능. 문파에 가입해 하나 배우고 탈퇴해도 된다.

## 용어 (먼저 읽을 것)
- **출혈**: 검이 쌓는 DoT. 최대 5중첩
- **혈폭 (과다 출혈)**: 5중첩에서 특수기(~) 또는 종횡검이 맞으면 전부 터뜨리는 단발 대미지. **딜의 대부분**
- **강류**: 창Q(허무의 술잔) **10타** 달성 시 내 버프 피해 +20%. 4타 미만 물방울 +10%, 5~9타 용천 +15%
- **경신**: 창R(절연의 비상)·창Q가 적에게 거는 지속피해 취약 디버프. 최대 5중첩, 18초

## 심법 4칸
결의의 노래 / 광풍의 검기 / 굶주린 늑대 / 통찰의 눈

### 돌파별 효과
**결의의 노래**: 기본 공격/치유 시 80%로 결의 1중첩(8초, 피해+1%, 최대 5) / 1돌 중첩당 외공 관통 2 / 3돌 통제 상태 시 2배 / 4돌 확률 100%·지속 12초 / **5돌 추가 치확 4.6%** / 6돌 최대 중첩 시 추가 피해 1회

**광풍의 검기**: 기본 마무리 단계 재입력 [종횡검], 5중첩 출혈이면 전부 제거+과다 출혈 1회 / **1돌 종횡검 성공 시 인내력 8 회복 (사실상 필수)** / 3돌 종횡검 최대 시 다음 종횡검 확정 각성 / 4돌 과다 출혈 +15% / **6돌 출혈 2중첩 보존 = 더블 혈폭**

**굶주린 늑대**: 기본 허무의 술잔 버프 조건 5/10→4/8 / 1돌 버프 15초(2.0 이후 18초) / **3돌 피해 +10%, 시전 중 60% 피해 감소 + 방해 저항 = 창Q 슈퍼아머** / 4돌 10연타 시 강력한 물살 피해 +25% / **6돌(2.0 개편) 허무의 술잔 명중마다 [경신] 1중첩 → 창R 디버프 관리 불필요**

**통찰의 눈**: 기본 각성 피해 시 응신, 최대 시 간파(각성 피해 +10%, 5%로 피해 40% 감소, 10초) / 1돌 간파 중 피해량 1.5% 흡혈 / 3돌 간파 중 각성 확률 +3% / 4돌 집중치 +50% / 5돌 관통(2.0에서 명금→외공 속성으로 조정) / **6돌 간파 중 지속 피해 +20%**

### 돌파 우선순위
굶주린 늑대 3돌 → 광풍의 검기 6돌 → 굶주린 늑대 6돌 → 결의 5돌 → 통찰 6돌
※ 효과 크기 기준 추론이다. 공식 권장 글은 **확인 못 함**

## 무공 특성 (천부)
**선택 분기가 아니다.** 무술 레벨업·돌파로 해금되는 패시브다. 공식 패치노트에 이름이 나온 핵심 둘:
- 구현의 검무 **[출혈 체계 강화]** — 2.0에서 과다 출혈 경직 시간 증가
- 격류의 파동 **[지속 피해 강화]** — [경신] 15→18초, 결산 시 18% 각성 피해

그 외 스탯형 천부 목록은 **확인 못 함**. 별개로 **보스 천부(천부작)**가 있고 딜증·피감이라 챙기는 게 맞다.

## 비결
| 비결 | 역할 | 획득 |
|---|---|---|
| **신룡의 화염** | 암작(화염 DoT)이 **혈폭 터질 때마다 갱신**된다. 딜 메커니즘의 핵심 | 개봉 경계석 근처 NPC 양안의 물건을 훔쳐 낙구에게. 안 먹히면 만사록 해당 페이지를 열면 완료 |
| **태백취권** | 술 마시는 모션 전에 패링 캔슬 → 취기 진입, 이후 신룡이 즉발. 강인 + 시전 중 피해 15% 감소 | 확인 못 함 |
| **맹수의 돌격** | 원기 대비 딜 최고. 거리 좁히기 겸 마무리 | 개봉 밀조실, 구름위질주 → 허공섭물 |
| **격랑의 파도** (피리) | 광역 PvE 최강. 피리 소리 직후 패링 캔슬로 초탄 포기, 지속뎀만 | 확인 못 함 |

- **용의 진노**: 단일 최고뎀이나 원기 소모 과다. 전용 세팅(비결 피해·단피증) 아니면 비추
- **음양의 조화**: PvE에선 안 씀. 다만 구격은 확실한 인내력 회복 수단이 없어 보조로 쓰는 사람은 있다

## 사이클
**오프너 (창R 쓰는 기본형)**
```
검QQ 출혈 5중첩
→ 신룡의 화염 2타 꽂고 3중첩
→ 창R 콕 찍어 경신 1중첩
→ 창Q 10타 넣고 캔슬 (강류 ON, 경신 5중첩)
→ 검~~ (혈폭, 신룡 갱신)
→ 창~ (고정 출혈 1중첩)
→ 검~ → 검R+R → 이어감
```

- **0~2돌**: 창Q에 슈퍼아머가 없어 끊긴다. 검 위주 + 비결로 때우고 창Q는 안전할 때만 (추론)
- **3~4돌**: 위 오프너 그대로. 창R로 경신 주입 필요
- **6돌**: 창Q만 돌려도 경신이 생성·갱신 → **창R 생략**, 인내 관리도 쉬워진다
- 검~R~~는 검~~보다 시간을 더 먹어 쿨 맞출 때만. 검~RR이 혈폭 1회 더
- **탈진(그로기) 전용 버스트**: 구격은 기절 보너스가 없다는 불만 글이 있고, 전용 윈도우 자료는 **확인 못 함**
- **잡몹**: 격랑의 파도 + 창 광역

## 조율
**구격은 각성 중심이다. 딜맥의 정확도·치명 세팅과 방향이 다르다.**

### 조율 티어 (2026-02, 2.0 이전)
- 1티어: 각성 · 기세 · 최대 외공 공격 · 정확도 · 내공
- 2티어: 치명타 · 검 무술 피해 증가 · 보스 피해 증가 · 최대 명금 공격 · 민첩
- 3티어: 모든 무술 피해 증가 · 비결 피해 · 최소 외공

### 목표 수치
- **각성 확률 40% 전후가 1순위**
- 이상값은 정확도 89 / 치명 36이지만 **종결 조율로도 안 나온다.** 실제론 정확도 80중반 / 치명 20중반
- PvP 랭커의 "정확도 100%"는 구격 PvE에 그대로 안 맞는다
- 치명 40% 근처부터 정확도도 최대 명금보다 좋아진다
- 결의의 노래 5돌의 추가 치확 4.6%를 계산에 포함할 것
- 확인 방법: 캐릭터 정보창의 **괄호 안 수치**가 적 저항 적용 후 실효값(81렙 이상 적부터 저항 발생). 정확한 메뉴 경로는 확인 못 함

### 판정 규칙
정확도 판정 → 적중 시 각성 or 치명 판정. 정확도 100%에서 각성+치명 합 100%면 일반뎀·찰과상이 안 뜬다. 치명 상한 80%(추가 치명 20% 별도), 최종 치명 70% 이상이면 확정 치명 옵션 발동.

## 정음 (81제 기준, 2.0 이전 자료)
- 무기류·환: 1티어 **외공 관통**, 2티어 명금 관통
  - 외공 관통이 나은 이유: 외공 공격이 비결 딜까지 포함하고 수치가 3~4배 크다
- 방어구: 1티어 **출혈 관련 정음**(86제부터 등장)

### 5특옵 종결 (2026-09-22)
**각성 / 각성 / 기세 / 최대 외공 / 내공**
- 용의 진노를 안 쓰면 '비결 피해'보다 내공
- **단일 피해 증가(단피증)는 PvE에서 나쁘다.** 용진 박을 때만

## 장비 세트
- PvE: **무기 비준/참매 + 방어구 역상** (2026-01 인벤, 1.x 시절). 중섭은 강응 선호 의견도 있음
- **2.2 시점 PvE 종결 세트는 확인 못 함**
- 흔히 인용되는 비준+강응은 **PvP 랭커 세팅**이다

## 왜 어려운가
- **종횡검 타이밍**: 검 차징(R)으로 관통한 "직후 바로" 종횡검 → 내려찍기에서 캔슬이 유행이었으나, 핑·프레임이 나쁘면 혈폭이 안 터진다. **0.5초 늦게 눌러 올려베기에서 캔슬**하는 쪽이 성공률이 훨씬 높고 보스와 멀어졌을 때도 들어간다 (2026-09-30)
- **창Q 10타 미달 = 강류 미발동 → 한 사이클 통째로 손해**
- **인내력으로 딜한다** → 회피를 못 쓰고, 꼬이면 멈춘다. 광풍 1돌이 사실상 필수
- 37혈폭 사이클은 창~ 두 번째를 버프 끝자락 칼타이밍에 꽂아야 해서 한국 핑에선 비현실적
- 손실 규모: 35bb 사이클이 핑 50ms에서 32~34bb로, 모바일은 거기서 -2bb

## 51렙 진행
지금 시작 가능하다.
1. 두 무공 확보 (격류의 파동은 광란문 절학 또는 동굴 기연, 광풍의 검기는 귀문시장 '미지의 오래된 서적')
2. 굶주린 늑대 3돌
3. 광풍의 검기 6돌
4. 굶주린 늑대 6돌
5. 결의 / 통찰

### 심득 수급
- **시즌 상점 주당 심득 상자 최대 40개 전량 구매 (최우선)**
- 주간 심득 교체 탭 선택 교환(낱장) 600개
- 옥어패 주간 구매
- 태평무묘 각 단계 초회 + 주간 깨달음 증표 구매
- 진수전·거점·검무장: 심력 20당 심법 상자 1개
- 협경: 보스당 약 5개 (주 1회 2보스 = 10개)
- 채집은 매일 06시 리필

뉴비는 노란 6돌보다 **보라 심법 먼저**. 심법을 교환해도 돌파는 유지되니 나중에 유파를 바꿔도 손해가 적다.
**6돌까지 걸리는 기간은 확인 못 함** — 주간 상한 구조상 수개월 단위인 것만 분명하다.

## 열석 균(딜맥)과의 관계 — 중요
- **심법이 거의 안 겹친다.** 공유되는 건 결의의 노래 하나뿐이다. **심법 돌파가 가장 큰 매몰 비용이고 이전되지 않는다**
- **"둘 다 치명 빌드"는 틀리다.** 명금영은 **각성 중심**(1티어 각성·기세), 열석 계열은 **정확도·치명** 중심이다. 조율 방향이 다르고 정음의 유파 관통도 명금 관통 vs 열석 관통으로 갈린다
- 공유되는 건 **외공 관통 정음, 최대 외공, 내공** 정도. 세트와 조율은 상당 부분 다시 맞춰야 한다
- 성능 비교: "쉽고 편함 = 횡도, 세고 불편함 = 구격". 고점은 구격, 저점·편의성은 딜맥
